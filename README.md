## GitHub Pages पर 2 मिनट में लाइव करें (Install App तुरंत काम करेगा)
1. इस ZIP को अनज़िप करें और सभी रूट फाइलें (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `.nojekyll`, `backend/`) अपनी GitHub Repository के मुख्य (root) फोल्डर में अपलोड करें।
2. GitHub Repo में **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `/ (root)`** चुनकर Save करें।
3. 1 मिनट बाद आपका HTTPS लिंक लाइव हो जाएगा — उस लिंक को मोबाइल Chrome में खोलते ही **📲 इंस्टॉल ऐप** बटन 1-क्लिक में ऐप इंस्टॉल कर देगा और कोई भी पुरानी Cache Memory नहीं रुकेगी!
